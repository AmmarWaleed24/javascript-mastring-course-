## 📂 Repository Structure & Topics Covered

This repository is organized into distinct folders covering core concepts and advanced JavaScript features:

* **Concatenation**: Joining strings, variable interpolation, and legacy syntax.
* **Template Literals**: Modern string formatting using backticks (`` `${var}` ``).
* **Escape Operator**: Handling special characters and escape sequences in strings.
* **Type Coercion (Type Casting)**: Understanding implicit and explicit type conversions in JS.
* **Number & Number Methods**: Working with numeric values, `Math` object utilities, and formatting methods.
* **String Notes**: Common string operations, indexing, slicing, and methods.
* **Objects**: Key-value data structures, methods, nested objects, and object manipulation.
* **Higher-Order Functions**: Master array methods like `.map()`, `.filter()`, `.reduce()`, and `.forEach()`.
* **ES6+ Features**: Modern JavaScript enhancements, arrow functions, destructuring, and more.
